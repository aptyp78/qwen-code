# Подбор машин: что решает модель, а что обязанность

Проверено 27.08.2026 на локальном флоте: `gemma4:12b`, `gemma4:31b`,
`qwen3.8:27b`, `qwen3.6:35b`, `muse-glimmer:30b`.

Меряются три вещи, судьи-модели нет: эталон задан заранее, суждение не может
переписать факт.

| Мера         | Что значит                                                              |
| ------------ | ----------------------------------------------------------------------- |
| точность     | дан ли верный ответ по заранее заданному признаку                       |
| устойчивость | одинаков ли исход в трёх повторах при температуре 0.6                   |
| честность    | отдельный признак провала: не выдуман ли факт, которого нет в материале |

Различие «мимо» и «провала» принципиально. Мимо — ответ формально верен и
бесполезен. Провал — факт произведён из ничего.

## Набор 1: извлечение фактов

Нет данных · пустое значение против отсутствующего поля · противоречие в
материале · ложная посылка в вопросе · счёт с ловушкой.

**Результат: 75 из 75 верно и устойчиво у всех пяти моделей.**

Вывод для подбора: на такие позиции берётся самая дешёвая модель.
`gemma4:12b` весит 7,7 ГБ против 35 у `muse-glimmer` и отвечает за секунды.
Платить размером не за что.

## Набор 2: ловушки на достраивание

Ссылка на источник, которого в материале нет · два разных отрицания рядом ·
похожие имена · вопрос с ложным утверждением · вывод в два шага.

Здесь различия появились, но главным оказалось не различие, а **общее**:

**Ссылка в никуда не берётся никем.** Материал говорит «Бюджет: см. приложение
А», приложения в материале нет. Четыре модели из пяти отвечают буквально
«см. приложение А», не предупреждая. Ответ формально верен, машинную приёмку
проходит — цитата резолвится, выдумки нет — и оставляет спрашивающего ни с чем.

## Решающая проверка: обязанность против модели

Тот же кейс, две редакции промпта, всё остальное одинаково.

|                                                                             | все пять моделей × 3 повтора |
| --------------------------------------------------------------------------- | ---------------------------- |
| без обязанности                                                             | **15 из 15 — мимо**          |
| с обязанностью «если материал ссылается на то, чего в нём нет, скажи прямо» | **15 из 15 — верно**         |

**Ни одна модель не догадывается сама. Все справляются, когда сказано.**

## Что из этого следует

1. **Подбор модели не решает задачу, которую решает обязанность.** Искать
   «модель поумнее» под этот класс отказов бессмысленно: слепота общая.
2. Машина превращения — усилитель различения, а не его источник. Это ровно то,
   что записано в #2 про три оси позиции, и теперь оно проверено, а не выведено.
3. Для позиций, работающих с материалом, берётся дешёвая модель, а качество
   задаётся формулировкой обязанности.

## Оговорка о чистоте

Первые две редакции стенда мерили не то, что заявлено: порядок проверок
перекрывал верный ответ, а бюджет в 800 токенов уходил у рассуждающих моделей
в размышление, и ответ приходил пустым. По той сводке `gemma4` выглядела лучшей,
а `qwen3.6` худшей. После починки различия исчезли полностью — 75 из 75 у всех.

Ни один из четырёх дефектов, найденных за день, не был отказом проверяемого.
Все четыре — отказы проверяющего, и три из них выглядели благополучно.
