# Усиление СРТ: стенд разнопозиционного акта

Проверка второй ступени разделения труда — даёт ли различие позиций содержание,
которого нет ни в одном исходном корпусе. Замысел и мера: issue #1.

**Позиция — это тройка**, а не роль:

| Ось                | Что определяет                                         | Как задаётся здесь        |
| ------------------ | ------------------------------------------------------ | ------------------------- |
| знаниевые средства | что агент способен увидеть в материале                 | файл в `corpus/`          |
| машина превращения | как производится преобразование                        | локальная модель          |
| обязанность        | что агент делает всегда, независимо от вида результата | текст в системном промпте |

Имя, тон и место в конвейере позиции не создают: агенты, различённые амплуа
при общих средствах, дают стилевую вариацию одного ответа.

## Такт

По своду «Макин, Methodology to AI»: предъявление → вопрос к содержанию (не
оценка) → правка понятия или удержание с обоснованием. Остановка по состоянию,
а не по числу итераций.

## Запуск

```
python3 stand.py              # разнопозиционный прогон
python3 stand.py --control    # контроль: одна модель, один корпус, амплуа
python3 svod.py multi         # свод журнала в отчёт
```

**Контрольный прогон обязателен.** Без него эффект разнопозиционности
неотличим от эффекта «спросили три раза».

## Критерий приёмки

Все три условия сразу, иначе не засчитано:

1. появилось различение, которого нет ни в одном исходном корпусе;
2. оно правится вопросами по содержанию, а не по формулировке;
3. работа переведена в понятия, а не в отчёт о шагах.

Защита от подделки: за различение часто принимают новый термин. Надо показать
два случая, которые раньше считались одним, а теперь разведены.
